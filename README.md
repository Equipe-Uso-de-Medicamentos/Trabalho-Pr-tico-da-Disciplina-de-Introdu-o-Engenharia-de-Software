## Sobre o Projeto
O **IMED** é uma proposta de sistema de software focada em auxiliar pacientes (principalmente idosos e portadores de doenças crônicas) e seus cuidadores no gerenciamento do uso contínuo de medicamentos. O objetivo é reduzir riscos como o esquecimento de horários, a confusão de dosagens e interações medicamentosas perigosas, promovendo maior adesão ao tratamento e segurança clínica e autonomia ao paciente.

## Estrutura do Repositório
A infraestrutura do repositório está organizada de maneira direta na raiz para facilitar a avaliação:
* **Documentação (`.md`):** Todos os relatórios textuais estão no formato Markdown para leitura nativa, fluida e padronizada diretamente na interface do GitHub.
* **Protótipos Estruturais (`.fig`):** Os arquivos originais do Figma contendo o estudo de fluxos e arquitetura de navegação.
* **Protótipo de Alta Fidelidade (`.html`):** Design interativo em código web demonstrando a interface final e as lógicas de acessibilidade.

## Como navegar neste projeto

1. **Leitura da Documentação:** Basta clicar em qualquer arquivo com a extensão `.md` na lista de arquivos acima para acessar a documentação correspondente a cada etapa da Engenharia de Software.
2. **Visualizar o Protótipo Final:** Baixe o arquivo `prototipo.html` e dê um duplo clique nele para executá-lo em qualquer navegador web (Chrome, Edge, etc.).
3. **Analisar os Wireframes:** Baixe os arquivos `Baixa fidelidade - Trabalho de ES.fig` e `Média fidelidade - Trabalho ES.fig`. Acesse o site do [Figma](https://www.figma.com/), faça login e arraste os arquivos para a sua área de trabalho para abri-los.
